# Twitch Latency Mitigator

Twitchのライブ視聴で、取得済みの映像に対して再生が遅れたときに追いつくブラウザー拡張です。
標準コントロールバー内の **「ライブ追従: ON/OFF」** で切り替えます。

- ボタンは設定アイコンの左側にあり、標準コントローラーと一緒に表示・非表示になります。
- 初期状態は拡張の設定で選べます（未設定時はOFF）。OFFでは再生位置を自動変更しません。
- ONでは毎秒確認し、余分なバッファが5秒以上あれば、約2秒を残す位置へ前方シークします。
- シークの間隔は最低5秒。映像の一部を飛ばします。
- 自分で巻き戻したいときは、先にOFFにしてください。操作の意図は自動判定しません。
- 一時停止中・シーク中・バッファ不足・VOD・検出できた広告中は操作しません。
- 一時停止してもONの指定は維持し、再生再開後に追従します。
- ページ再読み込みやサイト内の別ページへの移動で、設定した初期状態に戻ります。プレイヤー交換にも対応します。

## 読み込み

Chrome / Edge向けのManifest V3拡張です。ビルドや依存パッケージのインストールは不要です。

1. `chrome://extensions` または `edge://extensions` を開き、開発者モードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリのルートを選択します。
3. Twitchの視聴ページを再読み込みし、コントロールバー内のボタンでONにします。

WSL上のフォルダーをWindows側のブラウザーで読み込む場合は、そのフォルダーをWindows側から開いて選択してください。

## 表示言語

ブラウザーの表示言語に合わせ、日本語・英語で表示します。日本語以外の言語では英語を使用します。
プレイヤーのON/OFF・ツールチップ・状態通知、設定画面、拡張の説明文が対象です。

## デフォルトの追従設定

拡張の管理画面から「拡張機能のオプション」を開くと、**「デフォルトでON（追従）」** を選べます。
変更は自動保存され、ページを開いたときや別チャンネルへ移動したときの初期状態になります。
設定変更によって、視聴中のON/OFFが勝手に切り替わることはありません。
未設定時はOFFで、保存先はブラウザーの拡張専用ストレージです。

更新後は拡張の管理画面で拡張を再読み込みし、Twitchのページも再読み込みしてください。

## 制限と検証

改善できるのは、映像が先まで届いているのに再生位置が遅れた場合です。
映像が届く前に生じた遅延は、この方式では取り戻せません。
広告検出は完全ではなく、Twitchの非公開プレイヤーAPIへの依存もあります。

既存のEdge DevToolsセッションで `https://www.twitch.tv/stylishnoob4` に拡張と同じスクリプトを注入し、
ボタンの表示、OFFで巻き戻しを維持、ONで前方シーク、再びOFFで自動操作が止まることを確認しました。
設定の初期適用・手動OFFの維持・ページ移動時の初期値再適用も、実ページへ設定メッセージを送って確認しました。
さらに検証用Edgeへ拡張を実際に読み込み、設定画面から実ストレージへの保存、ページ再読み込み後の復元、デフォルトON、視聴中の手動OFF維持を確認しました。

テストは `node --test tests/*.test.mjs` で実行できます。
